# POE 流放之路网页市集插件

面向国服网页市集的 Chrome + Tampermonkey 用户脚本，为搜索页面增加收藏夹、历史记录、临时固定商品和装备文本翻译功能。

当前版本为不兼容旧版数据的 `3.0.0`，旧版快捷搜索功能已经移除；装备文本翻译已按新版市集重新实现。

侧栏默认折叠，展开后可拖动左边缘调整宽度；折叠状态、当前页签和侧栏宽度都会自动保存。

## 功能

### 搜索收藏夹

- 使用文件夹整理搜索条件，支持图标、折叠和拖拽排序。
- 保存当前搜索，后续使用当前赛季重新打开。
- 支持重命名、用当前搜索更新地址、复制链接和删除；更新时保留原名称及排序。
- 文件夹支持归档、恢复、删除以及单文件夹导入导出。
- 支持全部收藏的 JSON 备份与追加恢复。

### 搜索历史

- 自动记录最近 50 条搜索。
- 相邻的重复搜索自动去重。
- 历史记录保留原始赛季，可一键重新打开或全部清空。

### Pinned Items

- 在普通商品结果上增加“固定商品”按钮。
- 在侧栏集中对比商品详情、物品图和价格。
- 支持定位原商品、取消固定和全部清空。
- 固定商品只存在于当前搜索页面；刷新或切换搜索后会清空，避免保留过期商品。

### 大型星团位置

- 识别普通搜索结果中的大型星团珠宝。
- 在商品图下方注入“天赋位置”入口，悬停或点击查看显著天赋位置。
- 市集局部重绘商品节点后会自动重新注入，不会重复生成入口。

### 装备文本翻译

- 在搜索结果商品图下方提供“复制英文”，调用市集自身的复制能力获取完整装备文本，翻译后覆盖到剪贴板。
- 页面左下角提供独立的“快捷翻译”浮窗，可粘贴游戏或市集复制的装备文本并翻译、复制英文结果。
- 使用锁定版本的 `cn-poe-utils@0.0.10`，翻译器和游戏数据均随脚本打包，不依赖运行时 CDN。
- 不再读取市集旧版 Vue 实例的 `__vue__` 数据，兼容新版动态结果节点。

### Cookie 导出

- 左下角提供“复制 Cookie”，读取当前交易地址适用的全部 Cookie，包含 Tampermonkey 有权访问的 HttpOnly Cookie。
- 点击后以标准请求头格式展示并自动复制，例如 `name=value; name2=value2`。
- Cookie 只在点击时即时读取并保留在当前页面内存中，不写入 GM 存储；关闭或刷新页面后即丢弃。

## 安装与开发

```bash
pnpm install
pnpm dev
```

类型校验和正式构建：

```bash
pnpm exec vue-tsc --noEmit
pnpm build
```

构建产物位于 `dist/poe-trade-plugin.user.js`，在 Tampermonkey 中安装即可。

## 数据说明

- 收藏、历史和界面设置保存在 Tampermonkey 的 GM 独立存储中，不使用市集页面的 `localStorage`。
- 3.0 不迁移旧版插件数据，也不兼容 Better Trading 的导出格式。
- 本插件备份只包含文件夹和保存的搜索，不包含历史、界面设置和固定商品。

## 支持范围

- Chrome + Tampermonkey。
- `https://poe.game.qq.com/trade/search*`。
- 不支持通货交换页和 PoE 2。

产品设计参考了 [exile-center/better-trading](https://github.com/exile-center/better-trading)，本项目使用 Vue 3 独立实现，没有复制其 Ember 源码或资源。
